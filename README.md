# 🎤 Rap Machine

Браузерная программа для записи рэпа: генерирует случайный бит, показывает текст строка за строкой в такт, а голос обрабатывается эффектами на «микшерном пульте» в реальном времени.

## Запуск

Ничего устанавливать не нужно — откройте `index.html` в Chrome/Edge. Или запустите локальный сервер:

```bash
npx http-server -p 8765
```

и откройте http://localhost:8765. **Используйте наушники** — иначе бит из колонок попадёт в микрофон.

## Возможности

- **Биты** — генерируются на лету в 10 стилях (Trap, Phonk, Drill, Rage, Plugg, Jersey Club, Brazil Funk, Boom Bap, Lo-Fi, G-Funk): каждый раз новый ритм, тональность, гармония и темп. Сайдчейн (808 «качается» от бочки), вступление без ударных и брейки каждые 8 тактов. Можно загрузить свой бит (mp3/wav) и указать BPM.
- **Звуки (киты)** — «Синтез», встроенный кит **RM Pro** (`kits/rm-pro`, CC0, сгенерирован `node tools/make-kit.js`) или **📁 Кит из папки**: выберите папку любого сэмпл-пака — файлы сами разложатся по именам (kick, snare, clap, hat, open hat, 808, cowbell, bell, perc). Чтобы добавить кит навсегда, положите его в `kits/` и пропишите в `kits/index.json`.
- **Текст** — бегущая строка в такт: отсчёт «4-3-2-1», подсветка текущей строки и полоса прогресса.
  - 🎲 случайный текст из встроенного банка рифм;
  - ✨ текст по теме/промпту (без ключа — встроенный генератор, с ключом 🔑 Claude API — пишет нейросеть);
  - ✎ свой текст.
- **Пульт эффектов** (фейдеры + крутилки, кнопка ON на каждом канале):
  MIC (уровень, low cut) · PITCH (понижение/повышение голоса ±12 полутонов) · DOUBLE (второй голос, например на октаву ниже) · ТЕМБР (глубже↔ярче + LOW/MID/HIGH) · ROBOT · CRUSH · DIST · FILTER · CHORUS · ECHO · REVERB · мастер ГОЛОС/БИТ/СЛУХ с индикаторами уровня.
- **Пресеты**: Низкий бас, Демон, Бурундук, Робот, Телефон, Радио, 8-бит, Пещера, Трэп-эхо, Хор, Монстр.
- **Запись** — сводится бит и обработанный голос; каждый дубль можно прослушать и скачать в WEBM или WAV.

Горячие клавиши: `Пробел` — репетиция/стоп, `R` — запись. Двойной клик по ручке или фейдеру сбрасывает значение.
